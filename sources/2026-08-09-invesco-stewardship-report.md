# Invesco UK Stewardship Code Report 2023

The indexed text of Invesco’s 70-page *UK Stewardship Code Report 2023* records, on printed PDF page 25, that Invesco and J.P. Morgan jointly hosted a Black History Month session with Professor Jason Arday about his experiences of the intersectionality of race and neurodiversity.
