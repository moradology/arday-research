# Pagination correction

SRC-421 described the checked Zwozdiak-Myers page as printed p. 123. Direct inspection of the preserved rendered image `zm-059.png` shows the page header **48**; the PDF page number is 59. The underlying passage is the same one described in SRC-421: it ends with the sentence about prescribed approaches to teaching, power relations, and student-teacher core values.

The correction applies to the comparator pagination only. It does not invalidate the localized textual comparison, but it does mean that C-474/C-475 and downstream narrative references must use **Zwozdiak-Myers printed p. 48 / PDF p. 59**. The source’s earlier “p. 123” wording is preserved as an archival error in the revision history of the related record, not as a second page claim.
