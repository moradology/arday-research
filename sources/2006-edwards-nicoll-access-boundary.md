## Relationship to Kahn and Arday

The article is the source Kahn cites for the claims that reflective-practice language forms part of professional-development discourse, is attractive because it invokes open-mindedness and questioning, and performs legitimating rhetorical work. Kahn also reproduces a short quotation attributed to Edwards and Nicoll at p. 123. Arday thesis p. 78 follows this argumentative sequence through Kahn’s review and uses close paraphrase.

This pass did not obtain Edwards/Nicoll’s primary text. The Stirling record identifies a published-version PDF but marks it under embargo; the direct Stirling route returned an HTML access response. ERIC provides metadata and abstract but its guessed full-text endpoint `https://files.eric.ed.gov/fulltext/EJ729026.pdf` returned an HTML error response rather than the article. The JSTOR stable item and PDF route both returned the same 5,815-byte HTTP 403 “Access Check” HTML on 2026-08-08. No direct Edwards/Nicoll text comparison is claimed.

## Status

Verified bibliographic and abstract record; primary-text comparison remains blocked by Stirling embargo, ERIC error, and JSTOR HTTP 403 access-check states. Do not treat Kahn’s quotation as a substitute for the version of record.
