# RGS-IBG Annual International Conference 2026 — Jason Arday event

The Royal Geographical Society’s current Chair’s Events page records a planned “A conversation with Professor Jason Arday” for Wednesday 2 September 2026, 1:10–2:10pm at the Ondaatje Theatre, as part of the Annual International Conference on “Geographies of inequalities: towards just places.” The page describes a fireside chat with conference chair Professor Peter Hopkins and says the session would be livestreamed.

The same current HTML now places a cancellation notice immediately above the event description: “This session has been cancelled at the request of the speaker.” The individual RGS URL redirects to the broader conference page rather than exposing a separate speaker record. The linked Ex Ordo endpoint returned the conference application shell and did not expose a usable session page in this capture.

## Evidence handling

This verifies that RGS publicly advertised the event and that the current RGS page records its cancellation. It does not establish that the event occurred, that Arday attended, or that a recording/transcript exists. Search-index/browser text still exposes the earlier scheduled wording; that stale manifestation is preserved as a changed-page discrepancy rather than silently harmonized.
