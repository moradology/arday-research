## Acquisition rules

- Preserve the original source URL and access date in a metadata record.
- Keep the original media type and checksum where possible.
- Do not claim a video or document is locally preserved unless the file exists here and can be opened.
- For blocked or streaming-only sources, retain the retrieval failure and preserve any legally available thumbnail, transcript, screenshot, or page metadata instead.
- Local copies are research-preservation copies; review the source’s copyright and terms before redistribution.
