# Published snapshot

This GitHub repository is a lightweight, source-led snapshot of the Jason Arday research archive. It contains the Markdown ontology, biography, timeline, claims ledger, source registry, research log, and smaller provenance captures.

Large local media and document binaries are intentionally excluded from this GitHub snapshot to avoid repository-size and rights problems. The complete binary archive remains in the local workspace and Google Drive; individual source records identify the omitted local assets and their hashes where available.

Snapshot policy: public-source records and evidence boundaries are preserved here, but absence of a binary from this repository must not be read as absence from the research archive. Claims remain classified as verified records, self-reports, attributed reporting, allegations, disputes, or unresolved unknowns.
