## Rules that prevent circular work

- Search each topic once at a defined depth; record the query and result boundary in `research-log.md`.
- Search results are leads, not records. Promote a lead only once into a canonical source record.
- Every source gets a stable ID and one canonical file location.
- Indexes contain pointers and short descriptions only; they do not duplicate full source notes.
- If a source has already been reviewed, improve its record rather than researching it again.
- If nothing new is found, record “no new sources” and move to the next action.
- If a page or record has disappeared, record the disappearance as a negative-space observation instead of filling the gap from memory.

## Definition of done for a source

- URL and source type recorded.
- Publication/access date recorded where available.
- Relevant entity/event/publication links added.
- Key claims extracted with page number or timestamp when possible.
- Duplicate check completed.
- Status and confidence assigned.
